# Lab 1

## variables.py
**Task:** Show a few variables and their types.  
**How:** Fixed values, print with `type()`.

## hello_user.py
**Task:** Read name, age, city.  
**How:** Three `input()` calls and one `print`.

## two_numbers.py
**Task:** Add, subtract, multiply, divide, remainder.  
**How:** Read `x` and `y`, print five results.

## temp_convert.py
**Task:** Celsius to Fahrenheit.  
**How:** Read Celsius, use `(c * 9/5) + 32`.

## name_strings.py
**Task:** Upper, lower, reverse, length of a name.  
**How:** String methods and `[::-1]`.

## tab_print.py
**Task:** Show tab and newline in output.  
**How:** One `print` with `\t` and `\n`.
